## 项目介绍
一个基于Qt框架开发的串口调试助手工具，用于实现计算机与串口设备之间的通信测试和数据交互。

## 项目背景
在嵌入式开发、物联网设备调试、工业控制等场景中，经常需要与串口设备进行通信测试。传统的串口调试工具要么功能单一，要么操作复杂，给开发人员带来了不便。本项目旨在提供一个界面友好、功能完备的串口调试助手，帮助用户快速进行串口通信测试，提高开发调试效率。

## 技术栈

### 开发框架
1. Qt 5.15.2
2. C++17

### 技术支持
1. Qt Core：提供核心功能支持
2. Qt GUI：提供图形界面支持
3. Qt SerialPort：提供串口通信功能

### 项目架构
| 核心版块 | 功能描述 | 实现文件 |
|---------|---------|----------|
| 界面层 | 提供用户交互界面 | widget.ui |
| 逻辑层 | 实现串口通信逻辑 | widget.cpp |
| 入口层 | 程序启动入口 | main.cpp |

### 项目文件结构
1. **main.cpp**：程序入口文件，负责创建应用实例和主窗口
2. **widget.h**：主窗口类头文件，定义类结构和成员函数
3. **widget.cpp**：主窗口类实现文件，实现串口通信逻辑
4. **widget.ui**：界面设计文件，定义界面布局和控件
5. **QtSerialPort.pro**：项目配置文件，定义项目依赖和编译选项

### 项目流程
1. 程序启动时自动检测可用串口设备
2. 用户选择目标串口并配置参数
3. 打开串口建立通信连接
4. 发送/接收数据（支持字符串和HEX格式）
5. 实时显示数据收发状态和字节数
6. 关闭串口结束通信

## 使用说明

### 操作流程
1. **启动程序**：运行编译生成的可执行文件，程序会自动检测并显示可用串口
2. **选择串口**：在串口下拉列表中选择需要连接的串口设备
3. **配置参数**：选择合适的波特率等参数（如有需要）
4. **打开串口**：点击"打开串口"按钮，建立通信连接
5. **发送数据**：
   - 在发送区输入要发送的数据
   - 选择发送格式（字符串或HEX）
   - 点击"发送"按钮
6. **接收数据**：
   - 选择接收显示格式（字符串或HEX）
   - 接收区会自动显示接收到的数据
7. **关闭串口**：点击"关闭串口"按钮结束通信

### 配置说明
- **波特率选择**：根据目标设备的要求选择合适的波特率
- **数据格式切换**：
  - 接收格式：点击"HEX显示"或"字符串显示"按钮切换
  - 发送格式：点击"HEX发送"或"字符串发送"按钮切换

## 注意事项
- 确保在操作串口前，目标串口设备已正确连接到计算机
- 选择与目标设备匹配的波特率，否则可能导致通信失败
- 使用HEX格式发送数据时，确保输入的是有效的十六进制数据
- 不要在串口打开状态下拔插串口设备，以免造成设备损坏
- 长时间运行时，注意接收缓冲区的大小，及时清空避免内存占用过高

## 问题与解决方法

### 问题1：无法检测到串口设备
- **原因**：设备未正确连接或驱动未安装
- **解决方法**：
  1. 检查串口设备是否正确连接到计算机
  2. 确认设备驱动已正确安装
  3. 点击"刷新串口"按钮重新检测

### 问题2：打开串口失败
- **原因**：串口被其他程序占用或权限不足
- **解决方法**：
  1. 关闭可能占用该串口的其他程序
  2. 以管理员身份运行本程序
  3. 检查串口设备是否正常工作

### 问题3：数据收发异常
- **原因**：波特率不匹配或数据格式错误
- **解决方法**：
  1. 确认双方使用相同的波特率
  2. 检查数据格式设置是否正确
  3. 尝试使用不同的数据格式发送
  4. 检查串口设备的通信协议是否与发送的数据格式匹配
